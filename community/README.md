# Photonica community projects

Every `.photonica` file in [`projects/`](projects) appears in Photonica under **Community > Browse**, where it opens with one click.

## Share a bench

1. In Photonica, choose **Community > Share this bench to the community…**, and fill in a title, your name and a short description.
2. Photonica saves the file to `Documents\Photonica` and opens GitHub's upload page for this folder.
3. Drag the file in and click **Propose changes**. With a free GitHub account, GitHub makes the pull request for you.

A check runs on every pull request. Once it's merged, the gallery updates automatically.

## Rules

- One bench per file. Use a short `kebab-case` file name, e.g. `newtons-prisms.photonica`.
- Include a title, an author and a sentence on what the bench shows.
- At most 2 MB per file, 200 parts and 4 screens.
- Keep it about optics. Benches are plain data (parts, materials, camera, timeline), and nothing in them runs.

## For developers

`gallery.json` is generated by [`tools/build_gallery.py`](../tools/build_gallery.py), so don't edit it by hand. Its format is:

```json
{"format": "photonica-gallery", "version": 1,
 "projects": [{"title": "...", "author": "...", "description": "...", "url": "https://raw.githubusercontent.com/...", "parts": 3}]}
```

Any page can link a project directly. Photonica opens `https://…/file.photonica` links from **File > Open from link**.
